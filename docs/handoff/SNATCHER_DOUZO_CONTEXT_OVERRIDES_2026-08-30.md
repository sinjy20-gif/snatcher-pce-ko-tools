# `<원문 6자>` 문맥 충돌 분리 패치 — 2026-08-30

상태: **원인·대상 3개 확정, 주소별 override 적용 대기.**

## 1. 문제

일본어 `どうぞ`는 문맥에 따라 “들어와”, “그러세요”, “네/하십시오”가 된다.
게임은 같은 Shift-JIS 바이트열을 여러 장면에서 재사용하므로 원문 전역 치환이나
동일 원문 번역 통일을 하면 반드시 다른 장면 하나가 오역된다.

```text
<원문 6자>
82 C7 82 A4 82 BC 81 45 81 45 81 45
hash16 275F
```

해결 원칙: **원문 문자열이 아니라 overlay 주소/offset을 포함한 키로 분리한다.**

## 2. 확정 대상 3개

### A. 문을 열어주는 장면

```text
overlay       131800
source        27A0
JP            じゃあ、<원문 6자>。<원문 6자>
앞 문맥       “이제 이상한 짓 안 할 거지?” / “안 해, 맹세해.”
권장 KO       그럼 들여보내 줄게. 들어와…
핵심 치환     <원문 6자> -> 들어와…
```

이 항목은 독립 12 B 문자열이 아니라 긴 문장 안에 들어 있다. 현재 번역 방향이 맞다.

### B. 사진을 맡기는 장면

```text
overlay       131800
source        3B70
JP            <원문 6자>
앞 문맥       <원문 5자>、<원문 18자>？
              카트린느, 여기 사진을 잠깐 맡아도 될까?
뒤 결과       <원문 14자>。
              장의 사진을 맡았습니다.
권장 KO       그러세요…
```

현재 compiled 자료의 `들어오세요...`는 문맥 오역이다. 문을 여는 A와 동일 원문으로
통일된 흔적이므로 B는 반드시 주소별로 분리한다.

### C. 공격 개시 허가 장면

```text
overlay       159800
source        344E
JP            <원문 6자>
앞 문맥       メタル、いいか？いくぞっ！！
              메탈, 준비됐나? 간다!!
화자          메탈기어
권장 KO       네…
```

현재 master의 `먼저...`는 문맥 오역이다. 짧은 응답과 캐릭터 말투를 살려 `네…`를
권장한다. `진행하십시오…`도 의미상 가능하지만 원문보다 길고 과설명이다.

## 3. 현재 데이터에서 확인된 충돌

`snatcher_tool/translation/snatcher_ko_master.tsv`:

```text
R05781  <원문 6자>  들어와...  source_refs=34D0;3B70  카트린느
R07894  <원문 6자>  먼저...    source_refs=344E       메탈기어
```

`build/translation/current/compiled/overlay_compiled.tsv`:

```text
131800:3B70  <원문 6자>  들어오세요...
```

즉 master 단계의 동일 원문 병합과 compiled 단계의 문맥 오역이 모두 보인다.

## 4. 내일 작업 순서

1. 현재 번역 파이프라인이 overlay `source`까지 키에 포함하는 override 입력을 어디서
   받는지 확인한다. 전역 glossary/문자열 치환에는 넣지 않는다.
2. 아래 세 값을 주소 고정 override로 입력한다.

```text
131800:27A0  그럼 들여보내 줄게. 들어와…
131800:3B70  그러세요…
159800:344E  네…
```

3. compiled 산출물을 다시 만들고 세 주소가 서로 다른 한국어를 갖는지 검사한다.
4. 새 ROM을 빌드한 뒤 세 장면을 각각 실기 확인한다.
5. 동일 JP/hash 병합 경고를 빌드 검사에 추가한다. 동일 원문에 서로 다른 주소별
   override가 있으면 하나로 통일하지 않고 모두 보존해야 한다.

## 5. 완료 판정

- 세 장면이 각각 위 번역으로 표시된다.
- 다른 `どうぞ` 포함 문장에는 변화가 없다.
- `<원문 6자>` 전역 치환 규칙이 생성되지 않는다.
- 재빌드 뒤 일본어 원문이나 잘못된 `들어오세요...`/`먼저...`가 남지 않는다.
