★ 실전 주행에서 **진짜 버그를 하나 잡았다** — 경로에 괄호가 있으면

## C. 부팅화면 구조 — 디스플레이 리스트다

```
리스트  $00297D-$002A81  261 B   FF <팔레트> <x> <y> <타일...> · FF FF = 묶음
타일    $02C000                  ★ 타일 번호 == ASCII
팔레트  $02E182                  16 색 x 4 벌 (애니메이션)
```

지렛대는 리스트 안의 `56 45 52 2E 20 33 2E 30 30` = ASCII **"VER. 3.00"**.

원본 금색 타이틀을 그대로 옮기는 건 불가능하다 — 그라데이션 때문에 683 종 중
681 종이 고유하다. **납작한 2 색으로 다시 그리니 22x5 칸 92 종**으로 접혔고,

# 부록 2 — 한글화 조각이 사슬에서 빠져 있었다 (0.8.1)

## A. 소유자가 잡았다 — 가우디 인물검색이 통째로 없었다

디스크 문자열을 보고 판정하면 영원히 틀린다. 동굴이 비면 인물검색과 퀴즈가

⚠ 메모리 [[snatcher-gaudi-quiz-mapping]] 의 논리 오프셋은 안 맞는다.
