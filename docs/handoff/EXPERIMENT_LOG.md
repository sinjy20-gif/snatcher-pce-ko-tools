
## 0.4.5-space20 — 반각 공백 (2026-08-19, 폐기)

`SNATCHER_KO_SPACE=20` 으로 공백을 단일바이트 `20` 으로 내보낸 판.

```
빌드    SNATCHER_KO_BIOS=1 python build_snatcher_ko_0_4_5.py --space 20
데이터  '81 40' 0행 / 단일 '20' 1,640행 (정식은 정반대)  -- 인코딩은 정상 적용됨
결과    화면이 전각과 똑같다.  렌더러가 20 을 받고도 한 칸을 통째로 전진한다
```

**`--space 20` 은 "단일바이트 공백을 받아들이는" 경로일 뿐 칸 폭을 줄이지 않는다.**
진짜 반각을 원하면 렌더러의 칸 전진 로직을 고쳐야 하고, 그러면 UI 954 개와 본문
줄바꿈이 전부 다시 잡힌다.

부수 효과: 공백마다 1 B 절약 (1,640 행). 96 B 고정 레코드라 당장 이득은 없다.

소유자 판정: 전각(8140) 유지.  디스크 2 개(1.3 GB) 삭제.
