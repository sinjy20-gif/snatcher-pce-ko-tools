## B. FFFF 음성 173 건 — 관문이 두 겹이었다

키 가운데가 `FFFF` 인 음성만 자막이 안 떴다. 무작위가 아니다.

```
                length 중앙   길이 중앙    8.19초 초과
정상  918 건     0x5FA3        3.07 s        0 건
FFFF  173 건     0xFFBD       11.23 s      163 건
```

ADPCM RAM 이 64 KB 라 넘는 음성은 `adpcmLength` 가 포화한다 (`end = read+len -> FFFF`).

### ★ 관문 ① — AD_CPLAY 훅이 없었다 (`$F687`)

**BIOS 에 ADPCM 재생 루틴이 둘인데 훅은 한 곳에만 있었다.**
`$180D`(재생 시작) writer PC 를 대조해서 잡았다 (`0.5.142`):

```
정상 8/8    CTRL pc=$F61D v=60      $F61A 의 STA $180D
            KEYW pc=$F5EC / $F5E7   $22A6/$22A7 갱신
★SAT 1/1    CTRL pc=$F68A v=60      ★ 다른 PC ($F687)
            KEYW 없음
```

기존 훅은 `HOOK = $F5F5` (`AE A8 22` = `LDX $22A8`), 정상 셋업 루틴 안이다.
64 KB 초과 음성은 그 루틴을 안 지나가므로 **감지 시도조차 없었다** — 슬롯에
`A1`(찾음) 도 `A0`(미스) 도 안 떴다.

조건 확인 (`0.5.143`): `CDB_LBA($224D)` 는 그 경로에서도 진짜 LBA 를 들고 있다.

```
★SAT PLAY f1255   $224D=003123  len=FFC2  디렉터리 HIT slot 12
```

LBA 는 멀쩡히 있었고 우리가 가지러 안 갔을 뿐이었다. -> `0.4.6.69` 실기 PASS.

⚠ 출하 렌더러는 `timed=False` 로 굽는다 — `timed_advance` 블록은 아예 안 들어간다.


### 3 번이 성립한다 — 붙을 자리가 BIOS 에 있다 (0.5.160)

`0.5.160` 이 RCR writer 를 깨끗하게 떴다. **`$E42C` 하나뿐이고 BIOS 뱅크다.**
상주부(`$7Fxx`)도 스크립트 VM(`$6000~$7FFF`)도 아니라 감사 불변식에 안 걸린다.

덤프를 역어셈하니 `$E41F` 가 BIOS 의 "RCR 설정" 미니 서브루틴이었다:

```asm
$E41F  PHA
$E420  LDA #$06
$E422  STA $F7          ; VDC 레지스터 선택 그림자
$E424  STA $0000        ; 레지스터 선택 = 6 (RCR)
$E427  PLA
$E428  STA $0002        ; RCR lo   <- writer 로 잡힌 곳
$E42B  STX $0003        ; RCR hi
$E42E  RTS
```

형제 루틴도 같은 모양이다 — `$E42F`(reg 1) · `$E446`(reg 0).
